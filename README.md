# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shopping application.

## Project Features

- Browse houseplants by category
- View plant names, images, and prices
- Add plants to a shopping cart
- Dynamically update cart quantities
- Increase and decrease plant quantities
- Remove plants from the cart
- Calculate individual and total cart costs
- Responsive navigation
- Redux state management
- Checkout placeholder

## Plant Categories

1. Indoor Plants
2. Succulents
3. Flowering Plants

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Router
- CSS
- Vite

## Application

Paradise Nursery provides a simple and user-friendly shopping experience for customers interested in purchasing houseplants online.
